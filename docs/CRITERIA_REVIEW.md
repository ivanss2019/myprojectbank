## Что осталось для полного подтверждения

1. Настроить `ALPHA_VANTAGE_API_KEY` в локальном `.env` и обеспечить сетевой доступ.
2. Повторно запустить home/events с реальными API и проверить все курсы/цены > 0.
3. Подтвердить ставку потенциального повышенного кешбэка: по умолчанию 5%.

Нельзя считать нули, вымышленные котировки или null выполнением условия «float > 0».
Если за выбранный период нет пяти транзакций или трёх категорий, приложение
не дополняет выдачу фиктивными записями; требуемая полнота проверена на данных задания.

Push и создание PR не выполнялись: они требуют отдельного подтверждения пользователя.
